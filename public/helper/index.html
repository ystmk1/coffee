피그마 연결 헬퍼 설치

fetch로 저장한 이미지를 피그마에 바로 넣으려면 이 작은 헬퍼를 한 번 설치해야 해요. 크롬 확장은 컴퓨터에 프로그램을 설치할 수 없어서, 크롬과 피그마 데스크톱 앱 사이를 이어 줄 헬퍼가 따로 필요해요.

이미지 저장만 쓴다면 설치하지 않아도 돼요.

1. 아래 명령을 복사하세요

powershell -NoProfile -ExecutionPolicy Bypass -Command "irm https://coffee.ystmk1.workers.dev/helper/install.ps1 | iex"

2. 실행 창에 붙여 넣고 Enter

Win+R→Ctrl+V→Enter

파란 창이 잠깐 떴다가 2초 뒤 저절로 닫히면 끝이에요. 관리자 권한은 필요 없어요.

1. 아래 명령을 복사하세요

curl -fsSL https://coffee.ystmk1.workers.dev/helper/install.sh | bash

2. 터미널에 붙여 넣고 Return

⌘+Space→"터미널"→⌘+V→Return

"fetch helper installed"가 나오면 끝이에요. 터미널 창은 닫아도 돼요. macOS에 기본으로 있는 Perl로 동작해요.

3. 크롬으로 돌아가 fetch 아이콘을 누르면 자동으로 연결돼요.

설치하면 하는 일

  • 헬퍼 파일 3개를 내 계정 폴더에만 넣어요: Windows %LOCALAPPDATA%\FetchHelper, Mac ~/Library/Application Support/FetchHelper
  • 크롬·엣지·브레이브에 "fetch 확장이 이 헬퍼를 부를 수 있다"고 등록해요 (Native Messaging, 현재 사용자만).
  • 이 컴퓨터 안에서만 열리는 작은 서버(localhost:47321)를 켜요. 인터넷에서는 접속할 수 없고, fetch 확장과 피그마 플러그인의 요청만 받아요.
  • 다운로드 폴더 안의 이미지만 피그마로 넘겨요. 아무것도 인터넷으로 보내지 않아요.
  • 6시간 동안 쓰지 않으면 스스로 꺼지고, 크롬이 필요할 때 다시 켜요.

설치 스크립트와 헬퍼의 전체 코드: install.ps1 · server.ps1 · host.ps1 · install.sh · server.pl · host.pl

제거

fetch 팝업의 피그마 줄에서 제거를 누르면 등록 정보와 헬퍼 폴더가 지워져요.
