시행일 2026. 10. 17. · 크롬 확장 "fetch", fetch 피그마 플러그인, fetch 헬퍼에 적용돼요.

fetch는 개인 개발자가 만든 무료 도구예요. 저장한 이미지와 방문한 페이지는 이용자의 컴퓨터 밖으로 보내지 않아요. 회원 가입이 없고, 광고·분석 도구를 쓰지 않으며, 어떤 정보도 팔거나 남에게 넘기지 않아요.

1. 이용자 컴퓨터 안에서만 쓰는 정보

클릭한 이미지·영상단축키를 누른 채 클릭했을 때만, 그 요소의 주소와 페이지 주소·제목, 게시물 정보(아이디·게시물 번호)를 읽어 원본 파일을 찾고 파일 이름을 만들어요. 인스타그램·핀터레스트에서는 원본을 찾으려고 그 페이지가 불러온 데이터를 컴퓨터 안에서 살펴봐요. 원본 주소가 페이지에 없으면 그 사이트(예: 인스타그램)에 해당 게시물 정보를 한 번 더 요청할 수 있어요. 이 정보는 저장에만 쓰고 운영자에게 보내지 않아요.
설정단축키, 저장 폴더, 파일 이름 규칙, 옵션. 크롬 동기화 저장소에 저장돼요 (크롬 동기화를 켜 두면 Google 계정을 통해 내 다른 PC에도 맞춰져요).
사용 기록저장 횟수, 파일 번호, 강아지 애니메이션용 기록(최근 저장한 이미지 주소를 줄인 값 최대 1,000개), 후원 카드를 보여 준 횟수. 크롬 로컬 저장소에만 있어요.
피그마 헬퍼피그마 연동을 켜면 저장한 이미지의 파일 경로·이름·폴더 이름, 영상이면 클릭한 장면(PNG)을 같은 컴퓨터의 헬퍼(localhost:47321)에 넘겨요. 헬퍼는 인터넷과 통신하지 않고, 영상 장면 파일은 하루 뒤 지워요.

2. 후원

후원 QR후원 카드와 팝업의 QR에는 송금 안내 페이지 주소(https://coffee.ystmk1.workers.dev, Cloudflare Workers)와 금액만 들어 있어요. 이 페이지는 토스 송금 화면을 열어 줄 뿐, 아무것도 기록하지 않아요. Cloudflare는 서비스 운영을 위해 접속 IP 등을 처리할 수 있어요 (Cloudflare 개인정보처리방침).
송금 정보송금은 이용자가 토스 앱이나 은행 앱에서 직접 해요. 계좌 이체의 특성상 운영자의 은행 거래 내역에 보낸 사람 이름과 금액이 남고, 이 정보는 후원 확인과 반환 요청 처리에만 써요. 토스 앱의 정보 처리는 토스의 방침을 따라요.
피그마 플러그인 결제Figma 커뮤니티의 Fetch 플러그인 결제는 Figma가 처리해요. 운영자는 카드나 결제 정보를 받지 않고, Figma가 알려 주는 판매 내역만 봐요. 무료 체험 사용 수는 피그마 안(이 기기)에만 저장돼요.
문의메일로 보내 주신 내용은 답변에만 쓰고, 처리가 끝나면 1년 안에 지워요.

3. 하지 않는 것

  • 방문 기록, 페이지 내용, 저장한 이미지를 수집하거나 서버로 보내지 않아요.
  • 광고, 분석·추적 도구, 제3자 SDK를 쓰지 않아요.
  • 정보를 팔거나 대출·신용 평가 등 다른 목적으로 쓰지 않아요.

4. 지우기와 문의

확장을 지우면 이 컴퓨터의 설정과 기록이 함께 지워져요. 헬퍼는 팝업의 "제거"로 지울 수 있어요. 문의는 fetchbypatch@gmail.com로 보내 주세요.

5. 바뀔 때

이 방침이 바뀌면 이 페이지와 확장 업데이트 안내로 알려 드려요. 다루는 정보가 늘어나면 미리 동의를 받아요.

Summary (English)

fetch is a free tool. It processes the media you click, page addresses and settings only on your computer to save and name files. Nothing about your browsing or saved files is sent to any server. With the Figma option on, file paths and video frames go only to a helper on the same computer (localhost). Donation QR codes contain only a link to a page that opens the Toss transfer screen; that page records nothing. No accounts, ads, analytics or third-party SDKs; no data is sold or transferred. The use of information received from Chrome APIs adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements. Contact: fetchbypatch@gmail.com
